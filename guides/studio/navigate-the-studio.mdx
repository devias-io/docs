The studio is the app a team works in. It is one window with a sidebar on the left, the current page in the middle, and an assistant and notifications that open beside the page.

## Regions of the studio

| Region | Contents |
| --- | --- |
| Sidebar | Home, Tasks, Documents, Workflows, Agents and Skills at the top, then a section for each installed module, such as People, Companies and Deals from the CRM. |
| Search bar | Searches records. `⌘K` opens the command palette instead. |
| Assistant | The default agent, in a panel on the right. `⌘J` opens it. |
| Bell | Notifications from workflows, modules, agents and teammates. `⌘I` opens them. |
| Settings | At the bottom of the sidebar: profile, members, modules, data model, views, navigation, API keys and more. |

## Home

Home summarises how the business is going: key numbers, open tasks, recent documents and shortcuts. What it shows depends on the installed modules. Money in comes from Invoicing and the pipeline from the CRM. Each card is a [block](/guides/customize-studio/blocks).

## Command palette

`⌘K` opens the command palette from any page. It creates records, jumps to pages, switches workspace and searches records as you type. Modules add their own commands.

## Notifications

The bell lists what workflows, modules, agents and teammates sent. `⌘I` opens the list beside the current page, so the page stays in place. Unread notifications have a green dot.

## Keyboard shortcuts

| Press | Result |
| --- | --- |
| `⌘K` | Open the command palette |
| `⌘J` | Open the assistant |
| `⌘I` | Open notifications |
| `G` then `R` | Go to records |
| `G` then `S` | Open settings |
