A **task** is a unit of work. It can be given to a person or to an agent, linked to the records and documents it is about, and followed to done.

## List and board

The **Tasks** page shows tasks as a list or as a board. Both use the same filters, so switching keeps the filter. To add a task, type a title in the **Add a task** row and press Enter.

| Shortcut | Shows |
| --- | --- |
| All | Every open task |
| My tasks | Tasks assigned to the current person |
| Due this week | Tasks due in the coming days, soonest first |
| Overdue | Tasks past their due date |
| With agents | Tasks given to an agent |

The page can also show open work, closed work or both, search by title and filter by priority. The board has one column for each status. Dragging a card to another column changes its status.

## Properties of a task

| Property | Value |
| --- | --- |
| Title and description | Text |
| Status | `backlog`, `todo`, `in_progress`, `in_review`, `done` or `canceled` (shown as Backlog, Todo, In progress, In review, Done, Canceled) |
| Priority | `urgent`, `high`, `medium`, `low` or `none` |
| Assignee | A person or an agent |
| Due date | A date |
| Parent task | Another task, to break big work into smaller pieces |
| Links | The records and documents the task is about |

Each task also has comments and a timeline of everything that happened to it.

## Give a task to an agent

Choose an agent as the assignee. The agent works through the task for the person who assigned it. Anything it proposes that changes data waits for that person's approval before the task moves to review. The run can be stopped or retried from the task.

<Note>
  Only agents with **Takes tasks** turned on can be given tasks.
</Note>
